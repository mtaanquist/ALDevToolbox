AL Dev Toolbox Design System
Foundations Color Semantic & status Typography Spacing & shape Components Buttons Forms Cards Tabs Status pills Data table Overlays States Page chrome Code

A Business-Central-native design language for AL Dev Toolbox. Teal drawn from the BC control-add-in palette, cool-slate neutrals, and the Segoe UI system stack — one token layer, one component vocabulary, light and dark. Every specimen names the CSS class it ships as, so it ports straight into the Blazor components. Flip the theme, top right.

01

Color — brand & neutrals

Primary is BC's teal #008089 as the text-bearing action fill (white labels clear AA); the brighter BC primary #00B7C3 is the accent — focus rings, active bars, selected borders. Neutrals are a cool slate carrying a faint teal bias so they sit under the brand rather than fighting it.

Brand--primary · --primary-strong · --accent · --primary-weak
Neutrals — surfaces & ink--bg · --surface · --border · --ink*
02

Semantic & status

Sentiments derive from BC's Favorable / Ambiguous / Unfavorable, but the text tokens are darkened to clear 4.5:1 on white (BC's raw mustard and coral don't). Each ships a --x text, --x-bg tint, and --x-fill solid. The four XLIFF translation states keep their dedicated tokens.

Semantic--success · --warning · --danger · --info
Translation states (XLIFF)--st-untrans · --st-fuzzy · --st-trans · --st-final
03
