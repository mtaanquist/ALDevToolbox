Spec

Head

  • Crumbs "Upgrades > {name}". State pill uses the same tones as the Open view: Planned queued, In progress running, Updated warn, Done succeeded.
  • Meta row: Target, Planned, Environments, Progress ("5 of 8 updated, 3 checked": checked lines count as updated), Created, and Closed on a done upgrade.
  • Ribbon: one primary that follows the state, then outline Add environments..., Move dates..., Start update..., Change the next version..., then the overflow. No lines: Add environments... is primary and the others are disabled. Planned or In progress: Start update... is primary and runs over the lines not yet sent. Updated or every line checked: Mark done... is primary. Done: no ribbon, only Reopen and "New upgrade from the leftovers" in the overflow.
  • The four ribbon actions open the fleet table's existing dialogs (preview, typed confirmation, per-row results), filled in from the header's target version and slot. No new dialog is drawn for them.

Lines

  • Two columns, Now and State, as the brief proposes: Now is the live Business Central mirror, State is the upgrade's own word. State tones: Planned queued, Date moved muted, Booked info, Running running (pulse), Updated warn (a check is owed), Failed failed, Checked succeeded. Failed and Checked are the only red and green pills, so they read from across the table.
  • Checked: one tick plus a short note, stamped with who and when. The tick is enabled once a line is Updated or Failed; before that it is disabled with "After the update". The note sits under the stamp, so a short fixed list of checks can go there later.
  • Assignee: blank shows a quiet "Assign" button that opens a people menu. Set shows avatar and name, and clicking it reopens the menu.
  • Contact: name, with the phone as a tel: link. The Solutions list rail's contact markup is not in this project yet (#906 addendum), so this is a stand-in to swap for the rail's rendering.
  • Command bar: search, Mine switch, state filter. With a selection it adds Move dates..., Start update..., and More (Change the next version..., Assign to..., Remove from upgrade). Remove is disabled while anything in the selection has been sent.
  • Done: controls are removed, not dimmed, so the record reads at full contrast.
