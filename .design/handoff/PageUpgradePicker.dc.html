Spec

Picker

  • The Fleet table's columns and the Environments list's filters (search over solution, short name and environment; solution, type, view) inside a 1000px dialog. The dialog has a fixed height, and only the table scrolls.
  • Selection is a set of IDs held by the dialog. Search, filters and Show selected only change what is shown, so a ticked line stays ticked when it scrolls or filters out. The footer says "4 selected, 1 shown" when they differ.
  • Fill buttons add to the selection, never replace it. The version comes from the upgrade's target. They skip locked lines and lines already on the target.
  • Locked: on this upgrade = ticked and disabled, "Already on this upgrade". On another open upgrade = unticked, disabled, its name in --warning-text.
  • Primary: "Add environments" (disabled) at 0, then "Add 1 environment" and "Add 4 environments".

Add to upgrade

  • A radio list of open upgrades (name, target, slot, line count), then New upgrade, which opens Name and Target inline. The slot is left for the upgrade page.
  • Ticked environments are listed below with a tick or a warning. Environments on another open upgrade say which one and "Left out", and the primary counts only the rest: "Add 6 of 8".

Palette

  • Components.dc.html has no command palette section, so no note was added there. When the palette sheet from 2026-09-command-palette.md is drawn, list Upgrade as a result kind with name, target and state pill.

Files

  • UpgradePicker.dc.html, props mode (picker | add), preset, compact. The Open upgrades tile is drawn here only; PageDashboard.dc.html is unchanged.
