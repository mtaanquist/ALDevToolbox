AL Dev Toolbox - design system - step 3

App shell

A CSS grid that pins the brand row, sidebar and top bar, and scrolls only the content column - so position: sticky inside a page body works as authored (the page header below is sticky - scroll inside a frame to see it engage). Sidebar nav is grouped and expandable, lower groups appear by role, and the footer is pinned. Both themes are live: the sidebar sub-list expands, tabs and menus respond, and the theme toggle reflects the panel it sits in. The shell's breakpoints are container queries against .shell-root, so every frame below declares the width it is demonstrating: the two primary frames are a 1440px desktop scaled to fit, and the narrow demos are real 1000px and 600px containers.

Spec

Files

  • shell.css - the shell layer. Depends on tokens.css and components.css; no raw hex.

Layout

  • .app is a 2x2 grid: grid-template-columns: var(--nav-w) 1fr, rows: var(--top-h) 1fr, areas "brand top" / "nav content". The shell itself is overflow: hidden; only .app__content scrolls.
  • Because the scroll container is the content column, position: sticky works inside pages - .page-head--sticky is the canonical use.
  • The brand cell and top bar share one continuous bottom rule; the brand cell also carries the sidebar's right rule so the two meet cleanly at the corner.
  • Sidebar is a column flex: .app__nav-scroll takes the slack and scrolls, .app__nav-foot is pinned.

Sidebar classes

  • .app__brand, .brand__mark, .brand__name, .brand__toggle (drawer button, hidden on desktop).
  • .app__nav, .app__nav-scroll, .app__nav-foot.
  • .nav-group (+ .nav-group__label) - second and later groups get the divider automatically via .nav-group + .nav-group, so the Admin and Site administration sections need no extra markup when a role hides them.
  • .nav-item + __icon / __label / __badge / __caret, states .is-active (teal tint, teal text, 3px --primary accent bar via ::before), :hover, :focus-visible, .is-disabled.
  • .nav-parent + .nav-sub, with .is-open (expanded, caret rotates) and .has-active-child (parent reads as emphasised while a child is current). Sub-items are 30px and drop the accent bar.
  • .quota + __row / __val / __bar / __fill, escalating to .quota--warn at 75% and .quota--danger at 90%; .nav-links / .nav-link-btn (GitHub, docs, BC client, issues); .nav-copy.

Top bar classes

  • .app__top, .app__top-lead (drawer button + global search), .app__top-cluster, .top-sep.
  • .theme-toggle / .theme-toggle__btn + .is-active - three segments, light / dark / system, sun / moon / monitor icons.
  • .user-btn + __avatar / __meta / __name / __org / __caret. Name on line one, org and role on line two; the org line drops below 1280px.
  • Sign-out is a .btn--icon (log-out). The unauthenticated shell replaces the whole cluster tail with one .btn--primary "Sign in".

Reconnect overlay (Blazor Server)

  • .reconnect covers the shell (absolute, z-index 60, tinted + blurred), so the app is visibly blocked but still legible behind.
  • .reconnect__card has a 3px top rule: --warning while retrying, --danger-strong under .reconnect--failed. Parts: __title, __text, __attempt (mono, attempt count and countdown), __actions.
  • Retrying shows .spinner--lg + "Retry now"; failed swaps to a wifi-off icon and offers Reload plus Service status. Copy states explicitly that unsaved work is held in the tab, since a dropped circuit looks like data loss.

Responsive

  • >1280px full shell, 248px sidebar. <=1280px sidebar 208px, tighter gutters, org line hidden - laptop widths stay fully usable.
  • <=1080px 52px icon rail: labels, carets, group labels, quota and copyright hide; sub-lists are suppressed (parents navigate instead); title attributes carry the names.
  • <=760px off-canvas drawer: sidebar leaves the grid, .app.is-drawer-open floats it over the content at full --nav-w with labels restored, toggled by .brand__toggle in the top bar.

Tokens used, none added

  • --nav-w 248px and --top-h 64px drive the grid directly; everything else resolves from step 1. Wrapping .app in .u-compact switches the whole shell and its page to compact density.
