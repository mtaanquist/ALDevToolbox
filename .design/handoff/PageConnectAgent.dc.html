This is the only time the token is shown Store it in your client's secret store, not in a repository. If it leaks, revoke it from your profile - revocation is immediate.
Add the server to your client Paste this into your MCP client's config, then restart it. The manifest loads on first call.
mcp-config.json 
{
  "mcpServers": {
    "al-dev-toolbox": {
      "url": "https://toolbox.cronus.example/mcp",
      "headers": { "Authorization": "Bearer ${ALDT_TOKEN}" },
      "timeoutMs": 30000
    }
  }
}
Works with any MCP client. Set ALDT_TOKEN in the environment rather than inlining the token.
