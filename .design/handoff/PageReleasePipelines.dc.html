Spec

Structure

  • Archetype 2 unchanged: .page-head, .filter-bar (search, solution, environment type, pill tabs), .data-table--edge, .pager. One .btn--primary per state: "New deployment pipeline" in the head, or the empty state's action when the head has none.
  • Columns in reading order for the morning scan: Pipeline (solution below) / Environment (type and health below) / Deployment / Next deployment / Apps from / Installs. Deployment comes before configuration because it is what changes overnight.
  • Default sort is by delivery urgency: shipping now, needs attention, scheduled, then the rest. The tabs filter to those same groups.

Row state

  • Same rule as every table: leading glyph plus right keyline, word in aria-label / title, no Status column. Mapping: is-running shipping now (spinning arc), is-failed last deployment failed (cross) or environment missing / failed (alert), is-queued scheduled (clock) or handed to Business Central (arrow), is-succeeded deployed, is-cancelled cancelled or environment being deleted.
  • Shipping now is loud three times: a Shipping now band above the table (--info-bg, --bar-running keyline, large spinner, step count and progress), the row tinted --info-bg, and the Deployment cell in --info-text with a progress bar. The band is the across-the-room signal; one per live deployment, gone when nothing ships. Uploading uses the same band with "Uploading 3 apps" and an indeterminate <progress>.

Risk marks

  • Production is set in --danger-text semibold wherever an environment type appears, the same tone as the detail page's danger pill, so a Production target is never a plain word among Sandboxes.
  • Force sync gets a warning triangle and --warning-text, with the consequence in the title: it can drop tables and columns and the data in them. Add is plain text.
  • Environment health: Ready is muted; Being deleted is warning; Failed and Missing are danger, and a missing environment also turns Next deployment into "Blocked".

Phone

  • Below the shell's 700px step the table becomes a stacked list with the same glyph and keyline: name and solution, then delivery, then next deployment, then a risk line only when there is one (missing environment, deleting, Force sync). The row menu button is 44px.
  • ReleasePipelinesBody takes compact here because inline styles cannot hold a container query; in the app this is the shell's own @container (max-width: 700px).

Files

  • ReleasePipelinesBody.dc.html - page body, props kind (populated | loading | no-solutions | no-pipelines) and compact. ShellFrame gained body="release-pipelines" and bodyCompact, and marks Deliver > Deployments as current. No new tokens or colours.
